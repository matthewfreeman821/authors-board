# Author's Board

A local-first visual reference workspace for fiction writers.

Keep characters, places and events connected on a visual board. Explore an event's relevant references, preserve author-entered notes, and calculate ages from optional dates without treating inferred information as story canon.

## Development status

**In development.** This repository is the public starting point for the project. It currently contains the project overview; the application source will follow after its public-file and licensing review. There is no installable release or hosted demo here yet.

A working local implementation exists. Feature acceptance, integrated testing and release preparation are still in progress. Creating this repository does not mean the product is complete.

## Product direction

- Organize separate stories with named characters, places and events.
- Arrange references on a spatial board, with search and alternatives to dragging.
- Connect references and inspect an event's directly linked context.
- Keep manual age and background notes separate from calculated ages.
- Save work locally, with clear failure and recovery behavior.
- Support trash, restoration and deliberate permanent deletion.

## Technical direction

Python, SQLite and a browser interface built with HTML, CSS and JavaScript. The application is designed to run on the user's own computer, using local storage and a loopback server rather than requiring a cloud account.

## Public delivery milestones

- Reviewed application source and an explicit license.
- Reproducible setup and documented verification commands.
- Tests for features, persistence, recovery and connected workflows.
- Fictional demonstration data and screenshots.
- Documented limitations and a reviewed first release.

Future changes will use ticket-linked commits and reviews. Earlier local development is not represented as an invented public commit history.
